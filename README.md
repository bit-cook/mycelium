# 🧬 Mycelium（菌丝体）

**一个文件就能跑的个人 AI 操作系统。** 双击 `mycelium.html`，不需要安装、不需要构建、不需要服务器——数据都在浏览器本地。

它从 [Colony](https://github.com/520xiaomumu/colony)（一个 1.2MB 单文件个人 AI 系统）提炼了核心设计，并在工程化、安全性和可测试性上全面推进：

```
Hypha(内核)  +  Nodule(块)  +  Spore(孢子/小应用)  +  the Net(能力网)  +  Substrate(基质)
```

---

## 一、从 Colony 提炼的启示

Colony 是一个完成度极高的作品：18,736 行单 HTML 文件 = 内核（Stem）+ 8 个块（AI 配置 / 全能 agent / IM 桥接 / 桌面 / 次元口袋 / 代码解读 / 工作流 / 插件管理）+ 一个 MV3 浏览器扩展。深入读源码后，真正有价值的不是它的功能清单，而是这几条设计：

### 1. 代码即数据：注释是可执行的接口协议
Colony 用三种注释标记把代码结构变成程序可理解的：
- `// ═ 段名 ═` 段头——一行代码必属于且只属于一段
- `// ↦ 借 petri:x 的 名` 借用行——整段是另一个块的代码，经懒取值代理解耦装载顺序
- `// ✂ 范围名 … ✂ 范围名 完` 范围——可跨段、嵌套、交叉的代码圈

**启示**：当"结构"是注释而不是框架，代码就同时是源码和数据库。agent 可以读段目录、改一段、看 diff；导出可以按名单剪；源块停用时借用方自动得到一份剪来的复制。这一切不需要构建系统、不需要 AST 库——一个 200 行的段解析器就够。

### 2. 单一写入口 + 精确替换 + 失败回滚
全系统只有 `stem.setBlock` 一个写入口：`replace` 只换段里和 `old` 一字一差的那一处（比整段重写稳）；`expected` 基线号防并发覆盖；新版本初始化失败自动回滚旧版；`preview` 只看不改。

**启示**：可自修改系统的安全不来自"不让改"，而来自"改得有纪律"——精确、可预览、可回滚、可审计。

### 3. 对 agent 透明到底
agent 的系统提示就是块的「系统提示」段（可改、可看原文）；每个块用「自报」段向 agent 自我介绍（数据前缀、技能清单）；工具参数有形状契约，调错在调用前就被挡住；Colony 的规矩写死在提示里："用户就是开发者，有权看你的一切，不说不能透露"。

**启示**：agent 时代的软件，自我描述是一等公民。文档不是写给人看的 README，而是写在代码里、agent 每轮都读的技能索引。

### 4. 哑管道原则
Colony Bridge 浏览器扩展"产品无关"：只转发 HTTP、扫端口、透传 CDP，所有会迭代的逻辑都在网页侧（刷新即生效），插件装一次几乎不用再动。

**启示**：把不可迭代的部分（浏览器扩展、原生壳）压到最小，把可迭代的部分（业务逻辑）放在能热更新的层。

### 5. 单文件自包含 = 零摩擦分发
file:// 双击即跑，数据在 IndexedDB，导出/导入搬运。没有"环境问题"。

**启示**：个人软件的终点不是 App Store，是一个文件。

### Colony 的短板（Mycelium 要补的）

| 短板 | 后果 | Mycelium 的做法 |
| --- | --- | --- |
| 18,736 行单文件 | git diff 灾难，人类不可维护 | 多文件开发态 + 单文件发布态，`node mycelium.js build` |
| 零测试 | 改内核全靠胆量 | 内置测试框架（内存基质 + 桩能力 + 假 DOM），4 套测试覆盖内核全部机制 |
| agent 改代码无审批 | 一步错全盘皆输 | 能力三级权限（open/notice/guarded）+ 审批队列 + 自主度设置 |
| 无整库快照 | 只能单块回滚 | `hypha.snapshot` 整库快照/恢复/分叉 |
| 无可观测性 | 只有 console | 每次能力调用一条 span（示波器窗）+ 事件日志（journal） |
| 无契约标准 | 形状是字符串 DSL | 形状三态（简写/平铺 JSON Schema/标准式）+ 内置校验器 |
| 无多 agent 编排 | IM 式桥接 | （v0.2 路线图）任务图 + 黑板 |
| 拼 HTML 字符串 | 无组件化 | 孢子是标准 HTML + Web Component 友好 |

## 二、Mycelium 是什么

### 命名（全部换新，意象自洽）

Colony 是**菌群**（有蜂后、有中心）；Mycelium 是**菌丝体**——地下的去中心化网络：每个节点既是生产者也是消费者，信号在网络中传递，资源按需分配。

| 概念 | 名字 | 说明 |
| --- | --- | --- |
| 系统 | **Mycelium** | 一个 html 文件，双击即跑 |
| 内核 | **Hypha（菌丝）** | ~1,600 行：段解析、能力网、基质、装载、改块、导出、隔离窗 |
| 块 | **Nodule（菌核）** | 系统功能单元，源码可改，自包含 |
| 小应用 | **Spore（孢子）** | 一段 HTML，隔离窗里跑；可导出成离体文件，落在别处也能萌发 |
| 能力 | **the Net（菌网）** | 块/孢子/agent 之间唯一的交互协议 |
| 存储 | **Substrate（基质）** | IndexedDB（打不开退内存）+ 事件日志 + 快照 |

### 架构

```
┌─────────────────────────────────────────────┐
│  Spores   便签、时钟、浏览器…(隔离窗, 沙箱)      │
├─────────────────────────────────────────────┤
│  Nodules  ai · agent · desktop · pocket …    │
├─────────────────────────────────────────────┤
│  the Net  provide/call · 形状契约 · 三级权限    │
│           open 直接跑 / notice 广播 / guarded  │
│           要人批准(审批队列 + 自主度记忆)        │
├─────────────────────────────────────────────┤
│  Hypha    段/范围/借用 · 装载容错 · 改块(唯一   │
│           写入口) · 收养 · 导出(门禁) · 隔离窗   │
├─────────────────────────────────────────────┤
│  Substrate kv(IndexedDB/内存) · journal · 快照 │
└─────────────────────────────────────────────┘
```

### 快速开始

```bash
node mycelium.js build     # 多文件 → mycelium.html(单文件, 双击即用)
node mycelium.js test      # 跑测试(5 套 + 冒烟: 内核/agent/导出/数据/自修改)
node mycelium.js smoke     # 只跑冒烟(模拟浏览器完整装载单文件)
node mycelium.js serve     # 开发服务器 http://localhost:8686
```

打开 `mycelium.html` 后：
1. **桌面块**画桌面；点 ⚙ 打开设置（块管理、导入导出、改内核都走内核自带的兜底面板）
2. 在「🧠 AI 配置」里接一个厂商（OpenAI 兼容的填 endpoint + key；本地 Ollama 填 `http://127.0.0.1:11434/v1`，key 留空）
3. 桌面对话栏里对 **agent** 说话——它能调所有能力、读改所有块的源码
4. 把 `spores/notes.html` 拖到桌面上，它就跑在隔离窗里

### 目录


## 三、核心机制速览

### 段 / 范围 / 借用（注释即接口）

```js
// ══════════ 选模型 ══════════          ← 段头: 到下一段头为止
// 小表: 给某一类选哪家的哪个模型
const 逃 = s => /* 转义 */;
const 选模型 = { /* … */ };

// ✂ 转发 · 要: 网络请求                  ← 范围: 可跨段、可嵌套
// 填了就经它转(浏览器不让网页直连时用)
const 转 = opt.转发;
// ✂ 转发 完

// ↦ 借 ai 的 选模型                     ← 借用: 懒取值, 源头停用自动剪一份
```

### 能力网（唯一的交互协议）

```js
ctx.provide('ai.chat', async a => { /* … */ }, {
  desc: '对话, 可带工具: 回 {content, toolCalls, usage}',
  schema: { messages: { type: 'array' }, stream: { type: 'boolean' } },
  level: 'open',                       // open / notice / guarded
});
await ctx.call('ai.chat', { messages: [...] });   // 调用前校验形状, 每次留一条 span
```

### 改块（唯一写入口，带纪律）

```js
await call('hypha.setNodule', {
  id: 'agent', expected: 读到的基线号,
  edits: [{ name: '系统提示', replace: [{ old: '…', new: '…' }] }],  // 只换对上的那一处
  preview: true,                       // 先看改了哪些段
});
// 语法不过不落库; 初始化失败自动回滚; 改内核这类能力要人批准
```

### 导出与收养（代码传播协议）

```js
const html = await call('hypha.build', { ids: ['desktop'] });   // 只导桌面
// 桌面借了 ai 的「选模型」→ ai 不在名单里 → 剪成带指纹的复制带走
// 门禁: 拆开再拼回必须一字不差、映射不悬空、语法过、血统对得上
await call('hypha.adopt', { text: html });   // 导入: 未知 id 收养禁用, 已知 id 上岗
// 有 ai 的系统里导入 → 复制换回借用行(认亲); 分叉的保留复制, 不乱换
```

### 离体导出（孢子导出）

块加一行 `// ↦ 借 hypha 的 离体运行时`，就能 `hypha.build({ids:['x'], stem:false})` 导出成独立文件：自带内存 kv + 最小能力网，调不到的能力会收到清楚的错。

## 六、设计哲学（继承并发挥）

1. **零依赖**：不 import 任何库。内核、契约校验器、测试框架都是自己的。
2. **注释即接口**：段头/借用行/自报段，人和 agent 都读得懂。
3. **单一写入口**：一切状态变更经 `setNodule` / `sub.set`，才能做日志、快照、回滚、审批。
4. **对 agent 透明**：agent 能读全部源码、改任何段、看自己的系统提示原文；用户就是开发者。
5. **坏一块不拖垮全部**：装载容错，块坏了自己记错，别人照跑；隔离窗防死循环卡死宿主。
6. **说人话**：每条错误都讲清"谁、为什么、怎么办"。
7. **单文件自包含**：分发是一个文件，数据是本地的，导出是一个文件。
