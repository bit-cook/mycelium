01 · 启示

从 Colony 提炼的，不止是功能

Mycelium 的源头是 Colony—— 一个 18,736 行的单文件个人 AI 系统。深入读源码后，真正值钱的不是它的功能清单，而是这几条设计：

INSIGHT 01

🧩 代码即数据

段头、借用行、范围标记都是注释协议：代码结构因此可被程序理解、局部修改、按名单剪裁。一个 200 行的段解析器，胜过一整套构建框架。

→ Mycelium 继承并强化：门禁保证"拆开再拼回一字不差"
INSIGHT 02

🛡 改得有纪律

可自修改系统的安全不来自"不让改"，而来自唯一写入口：精确替换、基线号防覆盖、语法不过不落库、初始化失败自动回滚。

→ 再加上 guarded 审批：改代码这类事，人点头才做
INSIGHT 03

🔍 对 agent 透明到底

agent 的系统提示就是一段可改代码；块用「自报/技能」段向 agent 自我介绍；"用户就是开发者，有权看你的一切"写死在规矩里。

→ Mycelium 的 agent 提示词可读、可改、可换回
INSIGHT 04

🧪 哑管道原则

不可迭代的部分压到最小，可迭代的放在能热更新的层。Colony 的浏览器扩展装一次不用动，逻辑全在网页侧。

→ Mycelium 的启动器是全文件唯一物理不可改的代码
INSIGHT 05

📦 单文件自包含

file:// 双击即跑，数据在本地，导出/导入搬运。个人软件的终点不是应用商店，是一个文件。

→ 这个网站就运行着它：下面的演示就是真身
短板 → 补法

🔧 工程化全面推进

18,736 行单文件不可维护、零测试、改代码无审批、只能单块回滚、无可观测性——这些是 Colony 真实的短板。

→ Mycelium：多文件开发 · 5 套测试 · 三级权限 · 整库快照 · tracing

02 · 架构

五层，每层只做一件事

命名全部换新，意象自洽：Colony 是菌群（有蜂后、有中心），Mycelium 是菌丝体——地下的去中心化网络，每个节点既是生产者也是消费者。

🧫 Spore 孢子
小应用：一段 HTML，iframe 沙箱里跑，握手后才算就绪。可导出成离体文件，落在别处也能萌发。经 mycelium.call 调宿主能力。
🟢 Nodule 菌核
块：ai（多厂商协议适配）· agent（工具循环）· desktop（桌面/窗口）· pocket（数据守卫）。源码可改、可导入导出、坏一块不拖垮全部。
🕸 the Net 菌网
能力网：块/孢子/agent 之间唯一的交互协议。形状契约 + 三级权限（open 直接跑 / notice 广播 / guarded 要人批准）+ 每次调用一条 span。
🧬 Hypha 菌丝 · 内核
段/范围/借用解析、装载容错、改块（唯一写入口）、收养、导出（门禁）、隔离窗。内核自己也是"一块"：可改、可回滚、可导出。
🪵 Substrate 基质
IndexedDB（打不开退内存）+ 事件日志 journal（谁在什么时候写了什么）+ 整库快照 snapshot。
03 · 演示

下面跑的就是真身

这不是截图，不是视频——是托管在本站的 mycelium.html 原样跑在 iframe 里。 你的所有操作和数据都只存在这个浏览器标签里（IndexedDB），刷新不丢，关掉即散。

STEP 01

接一个大脑

桌面右下 ⚙ 设置 → 🧠 AI 配置：OpenAI 兼容的填 endpoint + key；本地 Ollama 填 http://127.0.0.1:11434/v1，key 留空。

STEP 02

对 agent 说话

右下角对话栏直接说"看看桌面上有什么"。它调 ui.state、读块源码、改代码——改之前会弹审批。

STEP 03

拖一个孢子

把 notes.html（便签孢子） 拖到桌面上，它就在隔离窗里跑，能经 data.set

STEP 04

导出整个系统

设置里「导出整个系统」得到一个全新的单文件——带着你的块改版和数据，发给别人双击即用。
